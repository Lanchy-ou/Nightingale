# Phase D Product Completion Plan — English Archive

## Sequence

D1 Identity → D2 Care Tasks/Patient Experience → D3 Transcript Reliability → D4 Evidence-Bound Copilot → D5 Security/Integration.

## D1

Invite, Argon2id registration/login, HttpOnly server sessions, logout revocation, DB-authoritative role/clinic/patient binding, demo auth explicitly gated.

## D2

First-class Task state machine, patient Start/Report done, clinic confirmation, exact optional provenance, patient-safe workspace.

## D3

Non-persistent deterministic transcript preview, fail-closed speaker ambiguity, reviewed canonical confirmation, frozen synthetic evaluation.

## D4

Clinician-only exact-evidence retrieval, explicit inference/unknown, editable drafts with confirmation tokens, no direct authoring.

## D5

SQLCipher storage/backup/restore, Caddy TLS, secure cookies/headers, exact-origin controls, secret/log hygiene, real session integration journeys.

## Completion boundary

Phase D engineering and automated security acceptance are complete. No real-clinician usability, production medical, public-host, penetration-test, capacity, or compliance claim is implied.
