## 本批实际改变

1. Glance 默认收起右侧工具栏；顶部 Sources & Copilot / Sources 可主动打开和关闭。精确来源仍通过原有接口打开。其他工作页保留原有栏布局。
2. 宽屏打开上下文仍为可调整宽度的并排栏；窄屏沿用抽屉。Glance 桌面也支持 Escape 关闭与焦点返回。
3. 列表减少重复符号与垂直间距，辅助信息从 11px 提升到 12px，原因从 13px 提升到 14px。所有原有重点、原因、审核状态与动作保留。
4. 操作位置按列表实际宽度变化，不再以整个窗口宽度猜测阅读区大小。展开 Details & ranking 后，解释获得整行空间。
5. Glance 来源以作者/事件时间、引文、原文高亮为主要内容，完整追溯链可展开。只保留一个可见的面板关闭按钮。其他页面暂时沿用原来源布局。

未修改评分、权限、病历数据、AI 出口、任务状态或患者端；未提交或推送代码。工作区已有修改保留，以本轮文件快照复核了增量范围。

## 本批视觉基准

| 元素 | 实际采用 |
|---|---|
| 背景 / 正文 | 沿用暖白 `#f6f5f1`、正文 `#202d32` |
| 品牌 | 沿用青绿 `#176e70`、浅底 `#e5f1ee` |
| 患者姓名 | 沿用 Georgia 衬线，桌面 34px |
| 功能标题 | 无衬线 24px；重点标题 17px、中等字重 |
| 原因 / 元信息 | 14px / 12px，不截断原有临床内容 |
| 列表节奏 | 行上下 14px，编号与内容间 12px，细分隔线 |
| 操作 | 来源浅青底，Review 次级描边，Details & ranking 低强调；保留选中、焦点与展开行为 |
| 手机动作 | 来源、Review 和详情入口至少 44px 高 |
| 来源引文 | 16px、青色左边框和浅底；原文精确 mark 保留 |

这是后续共同规范的起点。输入框、上传、危险操作和其他角色控件尚未统一，不能把本批说成共享组件库已经完成。
